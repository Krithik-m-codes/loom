# Security Policy

## Supported Versions

Loom is actively maintained. Security updates are applied to the latest release and the default `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

The Loom team takes security seriously. If you discover a security vulnerability in Loom, please follow responsible disclosure guidelines.

**Please DO NOT open a public issue.**

Instead, report vulnerabilities privately by emailing:
**`krithik.dev@gmail.com`**

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Your operating system and Loom version.

### Response Timeline
- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Status Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Once a patch has been verified and released.

We appreciate your efforts to responsibly disclose vulnerabilities and keep Loom secure for everyone.
